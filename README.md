# Oooverdose

Godot 4.7.2 Mono + C# 四轨下落式音游。双击 **Run.cmd** 自动构建并用指定路径的 Godot 启动游戏。也可以用 Godot 打开 `project.godot`，构建 C# 项目后按 F5 运行。

## 游玩

- 首页 → **开始游戏** → 选择谱面。内置原创合成示例曲 NEON FIRST LIGHT，无需下载音频。
- 使用物理键位 **D / F / J / K**，音符到达青色判定线时按键。长条按住直到尾部。
- **Esc** 暂停、继续；窗口失焦自动暂停。暂停菜单支持重开和返回。
- 判定：Perfect ±50ms、Great ±100ms、Good ±160ms，其余 Miss。长条头尾分别计分，尾部允许最多提前 130ms 释放。满分 1,000,000。

## 编辑谱面

首页 → **编辑谱面** → **新建谱面**，导入 MP3、OGG Vorbis 或 WAV。填写曲名、作者、BPM、首拍偏移，然后摆放音符。

- 首拍偏移为音频中第 0 拍的时间，单位秒，可为负数。恒定 BPM，4/4 小节。
- 单点工具：左键单击轨道。长条工具：左键拖动，同轨道的两个端点自动吸附；反向拖动也有效。
- 右键单击音符或长条身体删除；同轨道禁止音符重叠。
- 吸附支持 **1/4、1/6、1/8、1/12、1/16、1/24、1/32、1/64、1/128**。分母以全音符为单位；例如 1/4 是 1 拍，1/16 是 1/4 拍。
- 滚轮向上前进、向下后退一拍；Shift+滚轮按当前吸附间隔移动。底部时间轴定位整首曲目。左侧可调视图速度。
- **Space** 播放/暂停；速度选择 **0.25× / 0.5× / 0.75× / 1×**。采用变速变调预听。
- **Ctrl+Z / Ctrl+Y** 撤销/重做音符操作。文本输入框保持原生编辑快捷键。元数据修改不在音符撤销历史中。
- **Ctrl+S** 保存；**试玩**会先保存再进入游戏。返回时对未保存的修改提示确认。
- 编辑内置示例后保存会生成新谱面，保留原始示例。

谱面 JSON 和复制后的音乐位于 Godot `user://charts`（Windows 通常为 `%APPDATA%\Godot\app_userdata\Oooverdose\charts`）。移动文件夹时请同时保留音频，并更新 JSON 中的绝对 `MusicPath`。重新导入音乐不会自动伸缩已有音符。BPM、偏移修改影响网格，不会移动已放置音符。

## 验证

```powershell
dotnet build
& 'D:\Godot\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64_console.exe' --headless --path . -- --self-test
```

内置自检覆盖谱面持久化、所有吸附细分、偏移、音符与长条放置、重叠保护、撤销重做、判定、计分、暂停和页面导航。
