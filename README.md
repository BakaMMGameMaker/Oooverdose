# Oooverdose

Godot 4.7.2 Mono + C# 四轨下落式音游。双击 **Run.cmd** 自动构建并用指定路径的 Godot 启动游戏。也可以用 Godot 打开 `project.godot`，构建 C# 项目后按 F5 运行。

## 游玩

- 首页 → **开始游戏** → 选择谱面。内置原创合成示例曲 NEON FIRST LIGHT，无需下载音频。
- 使用物理键位 **D / F / J / K**，音符到达青色判定线时按键。长条按住直到尾部。
- **Esc** 暂停、继续；窗口失焦自动暂停。暂停菜单支持重开和返回。
- 判定：Perfect ±50ms、Great ±100ms、Good ±160ms，其余 Miss。长条头尾分别计分，尾部允许最多提前 130ms 释放。满分 1,000,000。
- 游玩/试玩时 D/F/J/K 每次按下都会播放音效，包括空按；命中不会额外叠播，按住不连发。长条成功结束另播一次尾音。首页和游玩左侧可选择「方块咔嗒」「清脆点击」「低沉 Pu」三种原创合成音色，调整独立音量；音量为 0 时静音。支持和弦叠音。全局音色、音量自动保存，重启保留。

## 编辑谱面

首页 → **编辑谱面** → **新建谱面**，导入 MP3、OGG Vorbis 或 WAV。填写曲名、作者、BPM、首拍偏移，然后摆放音符。

- 首拍偏移为音频中第 0 拍的时间，单位秒，可为负数。恒定 BPM，4/4 小节。
- 顶部左侧点击「单点 / 长条」按钮切换工具，旁边选择吸附精度。单点左键放置，长条左键拖动；两个端点自动吸附，反向拖动也有效。
- 顶部「收起左栏 / 展开左栏」控制参数侧栏，「判定线动画 / 收起动画」控制右侧动画栏；可以独立收起，也可以全部收起专注排键，状态在本次运行内保留。常用操作提示放在悬停提示中。
- 左侧栏提供「编辑轨道」下拉框、「新建轨道」及名称输入框。编辑轨道是乐器分组，与 D/F/J/K 四个按键列独立；旧谱面和默认 note 都属于轨道 1，新 note 归属当前编辑轨道。新建后自动选中，可命名为「鼓组」「钢琴」等。分组与名称随谱面保存，试玩返回保留当前选择。
- 当前编辑轨道的 note 正常显示并播放过线音效；其余轨道的单点、长条半透明压暗，不播放过线音效，也不会被右键删除。播放中可切换当前轨道，不会补播已过去的音符。右下方音符数显示「当前轨道 / 全部」。
- 游玩和试玩合并所有编辑轨道。为保证四键可玩性，同一按键列仍禁止跨编辑轨道重叠放置音符。撤销/重做保留 note 的分组；轨道新建和命名作为谱面信息保存，不属于音符操作撤销历史。
- 右键单击音符或长条身体删除；同轨道禁止音符重叠。
- 吸附支持 **1/4、1/6、1/8、1/12、1/16、1/24、1/32、1/64、1/128**。分母以全音符为单位；例如 1/4 是 1 拍，1/16 是 1/4 拍。
- 滚轮向上前进、向下后退一拍；Shift+滚轮按当前吸附间隔移动。底部时间轴定位整首曲目。
- 暂停编辑时，修改 BPM/首拍偏移、切换吸附精度及拖动底部时间轴会把 NOW 定位到吸附点；滚轮也以首拍偏移为基准定位。播放中的 NOW 是连续音频时间，通常位于两条节拍网格线之间。点选已有关键帧仍精确定位其原始时间。
- **Space** 播放/暂停；速度选择 **0.25× / 0.5× / 0.75× / 1×**。采用变速变调预听。
- 编辑器播放时，单点和长条头尾经过判定线会自动播放打击音效，无需按键。拖动定位不会为跳过的音符补播；暂停时不发声，回退后可重新试听。
- 每次进入编辑器都会复制当前全局音色和音量。「编辑器试听音效（临时）」中的调整仅在本次编辑器会话有效，不修改或保存全局设置，也不写入谱面。离开编辑器进入试玩、选曲或首页时使用全局音效；再次进入编辑器会重新读取全局设置。
- **Ctrl+Z / Ctrl+Y** 撤销/重做音符及判定线关键帧操作。文本输入框保持原生编辑快捷键。元数据修改不在撤销历史中。
- **Ctrl+S** 保存；**试玩**会先保存再进入游戏。返回时对未保存的修改提示确认。
- 保存、重复保存和试玩都更新当前谱面，不创建副本（内置示例同样如此）。之前清理重复示例时留下的 `charts/duplicate-backups` 是备份目录，不会作为谱面加载。

谱面 JSON 和复制后的音乐位于 Godot `user://charts`（Windows 通常为 `%APPDATA%\Godot\app_userdata\Oooverdose\charts`）。移动文件夹时请同时保留音频，并更新 JSON 中的绝对 `MusicPath`。重新导入音乐不会自动伸缩已有音符。BPM、偏移修改影响网格，不会移动已放置音符。

首拍偏移定义网格的音频时间原点：`网格时间 = Offset + tick × (60 / BPM) × (4 / 吸附分母)`。note 与动画关键帧写入时共用此公式，保存的是绝对音频秒数；游玩不会再次加 Offset。修改偏移不会自动移动已有 note 或动画关键帧。画布操作提示仅在鼠标静止约 0.65 秒后出现，移动、点击或移出画布立即消失。

## 判定线动画器

点击顶部「判定线动画」打开右侧的 Y 动画曲线和关键帧控件。Y 为轨道高度百分比：**0 顶部、100 底部，初始 90**。这是整张谱面的判定线动画，作用于所有编辑轨道。

- 用播放进度条、滚轮或动画曲线定位歌曲时间，填写「时间 s」「Y %」及过渡方式，点击 **K 写入**，或在非文本输入状态按 **K**。关键帧时间会使用当前 BPM、首拍偏移和节拍吸附（包括三连音等细分）进行量化。
- 在曲线上双击空白处插入当前求值高度的关键帧；单击圆点选中并定位，可修改时间、Y 和过渡后重新写入。修改选中帧的时间会移动该帧，目标时间已有帧时更新该帧。
- **删除** 或右键圆点删除关键帧；**‹ / ›** 跳到上一帧/下一帧。Ctrl+Z / Ctrl+Y 同时支持音符和关键帧操作。
- 过渡方式定义在**起始关键帧**上，作用于它到下一帧的区间：**跳变**保持起点值，到下一帧时跳变；**线性**匀速过渡；**三次平滑**使用 `3u²−2u³`，两端缓入缓出。
- 第一帧之前保持初始 Y=90，最后一帧之后保持最后的值。需要从歌曲起点开始渐变时，先在 0 秒写入一帧。
- 编辑器播放、定位和试玩按歌曲时间直接求值；变速预听同步减慢动画。播放中可定位预览，写入或删除关键帧需先暂停。关键帧随谱面保存，旧谱面无需转换。

音符仅根据到达时间计算判定线局部坐标中的匀速位移，再由判定线当前变换带到画面上。单点和长条头尾都随判定线移动，并在各自的 Time 时刻与判定线重合。屏幕上的运动是局部下落与判定线动画的叠加；判定与音效仍以歌曲时间为准，判定线跳变不会额外触发音效。

## 固定下落速度

编辑器、游玩和试玩的下落速率固定为 **1.0×**，玩家无法调整。旧版设置文件中的 `scroll_rate` 不再读取。

局部像素速度等于实际轨道视图总高度，固定为每秒谱面时间移动一个轨道高度。总高度包括判定线下方的区域。判定线静止时音符从顶部到底部需要 1 秒；添加动画后，画面中的运动会叠加判定线的位移。窗口或界面布局变化后会按新高度实时换算。

编辑器的 0.25× / 0.5× / 0.75× 变速预听仍可使用，例如 0.5× 时贯穿轨道需要 2 秒现实时间。全局音效设置保存于 Godot `user://settings.cfg`，谱面 JSON 不包含用户音效或下落速率设置。

```powershell
dotnet build
& 'D:\Godot\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64_console.exe' --headless --path . -- --self-test
```

内置自检覆盖谱面持久化、所有吸附细分、偏移、音符与长条放置、重叠保护、撤销重做、判定、计分、暂停和页面导航。
